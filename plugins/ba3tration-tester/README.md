# Ba3tration-tester plugin

One skill, `setup`: it sets up a Ba3tration-tester repo for your app, runs the engines and reads the report with you.
The same skill as a plain Agent Skill, for any coding agent: [skills/ba3tration-tester](../../skills/ba3tration-tester/SKILL.md).

```
/plugin marketplace add beait/Ba3tration-tester
/plugin install ba3tration-tester@ba3tration-tester
```
